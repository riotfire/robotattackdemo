# M2-J5 placeholder audio

These original, synthesized WAVs are generated by `tools/audio/generate_placeholders.py`.
They establish timing, mix buses, and cue wiring while final music and Foley are produced.
Regenerate with `python3 tools/audio/generate_placeholders.py`. Replace them before
shipping; the generator is deliberately simple and uses only Python's standard library.

`music/` holds the real songs, which are not generated: *Surveying the Field* (between waves)
and *Robot Attack Pixel Banjo Defense* (while robots attack). `music_intermission.wav`,
`music_siren.wav`, `music_combat.wav`, `music_boss.wav` and `music_cleared.wav` are no longer
played; see `docs/AUDIO_INTEGRATION.md`.
